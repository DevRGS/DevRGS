## 👋 Sobre mim

Comecei em 2022 com HTML e CSS nos vídeos do **Gustavo Guanabara** (meu [primeiro projeto](https://github.com/DevRGS/primeiro-projeto) ainda está aqui) e não parei mais: passei por JavaScript, Python, PHP e hoje construo aplicações completas com **React + TypeScript**.

Gosto de projetos que **funcionam sem servidor**: o navegador lê APIs públicas direto da fonte, o **Google Sheets** vira banco de dados e o deploy sai pelo **GitHub Pages** ou **Vercel**.

- 🔭 Trabalhando agora na **[Central de Linguagens](https://devrgs.github.io/Aprendendo-linguagens/)**, uma plataforma gratuita para aprender programação
- 🌱 Estudando Java, SQL e Node.js
- 💬 Pode me perguntar sobre React, TypeScript, GitHub Pages ou como usar Google Sheets como backend
- ⚡ Curiosidade: todos os meus projetos de estudo têm um link para você testar no navegador
